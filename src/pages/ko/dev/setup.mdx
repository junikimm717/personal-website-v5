# 개발 환경

## 컴퓨터

지금 개발에 쓰는 시스템입니다:

1. MacOS: M4 Pro Macbook Pro와 M3 iMac
2. Linux: System76 Darter와 Lemur Pro
3. 앱을 올려 둔 서버: Raspberry Pi, [mit.junic.kim](https://mit.junic.kim), 되살린 2012년형 DELL 데스크톱,…

어느 환경을 쓰든 설정을 최대한 같게 유지하려고 합니다.

## 터미널

터미널을 빠르게 쓰려고 주로 tmux와 zsh를 씁니다.

tmux는 제가 만든
[프로그램과](https://github.com/junikimm717/tmuxs) 연동해, 원하는 프로젝트로
바로 이동하게 해 두었습니다. 키 한 번으로 디렉터리를 검색할
수도 있습니다.

최근에는 oh-my-zsh가 느려서 플러그인을 직접 깔아 쓰는 설정으로
옮기는 중입니다.


```bash
export WORKSPACES=$HOME/Documents:$HOME/docs/programming:$WORKSPACES
bindkey -s "^f" "tmuxs -d 4\n"
```

## 편집기

9학년 때 빔(Vim)을 만난 뒤 계속 쓰면서, 최근에는 LSP
지원과 테마 전환을 직접 넣어 [제게 맞는
IDE](https://github.com/junikimm717/nvim2025)로 만들었습니다. 커밋이
날 때마다 Docker 이미지가 빌드되어, 누구든 바로 쓸 수 있게
해 두었습니다.

서버나 컨테이너에서 편집기를 급히 맞춰야 할 때는 [빔 설정
파일을](https://git.junickim.me/junikimm717/vim2023) 받아 두면 즐겨 쓰는 기능을 바로 쓸 수 있습니다. 아래처럼 터미널에 붙여
넣으면 됩니다.

```bash
# 모든 기능이 있는 설정 파일
curl -LJ https://git.junickim.me/junikimm717/vim2023/raw/branch/master/lsp.vimrc -o $HOME/.vimrc
# 플러그인을 최소한만 넣은 설정 파일 (Git 필요)
curl -LJ https://git.junickim.me/junikimm717/vim2023/raw/branch/master/minimal.vimrc -o $HOME/.vimrc
# 플러그인이 안 포함된 설정 파일
curl -LJ https://git.junickim.me/junikimm717/vim2023/raw/branch/master/noplug.vimrc -o $HOME/.vimrc
```

## 창 관리자

Linux에서 쓰던 MOD 키는 MacOS에서는 Alt로 바꿨습니다.

- `mod-shift-a` 터미널 열기
- `mod-shift-return` Tmux가 켜진 터미널 열기
- `mod-shift-w` 웹 브라우저 열기
- `mod-space` 앱 선택 메뉴 열기 (Raycast 또는 Rofi)

앱은 제가 정한 규칙에 따라 해당 창으로 갑니다.

1. 터미널
2. 웹 브라우저
3. 다른 편집기/개발 도구
4. 줌/회의 소프트웨어
5. 가상 머신 소프트웨어
6. 음악 플레이어
7. 컴퓨터 설정 도구
8. 디스코드
